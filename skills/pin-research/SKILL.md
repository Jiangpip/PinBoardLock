# 出一份 Pinterest 调研单

用户找参考图的流程是固定的：**说需求 → 这里出调研单 → 插件侧边栏“刷新”选它 → 去 Pinterest 按关键词收图 → 插件点“下载”存到本地（装了 Billfish 的还会写上来源和标签）**。这个技能只负责第二步：把聊出来的需求变成一个 JSON 文件，放到插件读的文件夹里。后面几步都是用户在浏览器里点，不要替用户开 Pinterest、下载图片或者动 Billfish。

工具在 `{{PBL_ROOT}}`。格式的权威说明是 `{{PBL_ROOT}}\sheets\调研单规格.md`，和下面写的有出入时以它为准。

## 1. 先把需求聊清楚

调研单好不好用，取决于分组是不是真的对应用户要解决的问题。动手之前要知道：

- **调研什么**：风格、题材、材质、构图，还是某个具体场景的气质。
- **拿来干什么**：给哪个项目、要解决什么画面问题（比如“溪谷的雾怎么压远山”“吊桥的结构细节”）。这决定按哪些角度分组。
- **放哪**：Pinterest 收藏夹（Board）叫什么；下载到本地的文件夹叫什么。

用户已经说清楚的不要再问。缺的一次问完，不要一条一条追问。收藏夹名和文件夹名用户没说时自己起一个并在回复里写明，不要为这个专门停下来问：收藏夹名用 `风格调研-<主题简称>` 这种短名字，文件夹名用调研主题。用户用别的语言交流时，标题、分组名、说明都用那种语言写。

是在已有调研单上补充时（同一个收藏夹继续收），先读 `{{PBL_ROOT}}\sheets\` 里那份原文件再改：**已有的分组名和分区名不要改**，因为 Pinterest 上的分区已经按这些名字建好、图已经收进去了，改名会多出一批空分区。只加新分组或给旧分组加关键词。

## 2. 写调研单

```json
{
  "title": "调研主题（中文）",
  "board": "Pinterest 收藏夹名",
  "folder": "下载到本地的文件夹名",
  "note": "这次调研要解决什么",
  "groups": [
    {
      "name": "分组名（也是收藏夹里的分区名）",
      "note": "这一组要看什么、怎么判断一张图合不合适",
      "keywords": ["pinterest search phrase", "another phrase", { "q": "wu guanzhong landscape", "note": "吴冠中" }]
    },
    { "name": "散图", "section": false, "keywords": ["不分区、直接进收藏夹的关键词"] }
  ]
}
```

- **分组**：按“看的角度”分 3–6 组（用色 / 笔触 / 构图 / 光线 / 代表作者 / 相邻风格 / 结构细节……），不要按关键词的字面相似度分。每组的 `note` 写清楚这一组要看什么，用户收图时侧边栏会显示这句话，它是筛图的标准。
- **关键词**：每组 4–8 个，写 Pinterest 上真能搜出图的词。以英文为主；这个题材在日文、中文圈更常见时把对应语言的词也放进去。要具体：作者名、流派名、技法名、年代、题材组合。只写 "beautiful art" 这种泛词搜出来全是噪音。拿不准的专有名词（作者、流派的英文写法）能联网就核对一下，不能就挑有把握的写。关键词需要解释时写成 `{ "q": "...", "note": "..." }`。
- **分区**：`section` 不写时分区名等于分组名。组名太长或带符号时用 `"section": "短名"` 另起一个。分区名会变成本地的文件夹名，所以不要带 `/ \ : * ? " < > |`。想留一组不分区、直接进收藏夹的，写 `"section": false`。
- **folder**：只写文件夹名（会放在默认根目录下面，默认根目录是 `{{PBL_ROOT}}\host\config.json` 的 `defaultRoot`），除非用户指定了别的位置才写完整路径。
- `title` 和 `board` 都一样就算同一份，再存一次是更新。

## 3. 存文件并检查

存成 `{{PBL_ROOT}}\sheets\<调研主题>.json`，UTF-8 不带 BOM，文件名里不要有 `/ \ : * ? " < > |`。然后跑：

```
node "{{PBL_ROOT}}\tools\sheet-check.js" "{{PBL_ROOT}}\sheets\<调研主题>.json"
```

它用的是插件同一份解析逻辑，会打印插件读进去之后的样子（收藏夹、下载到哪、每组几个关键词）和提醒。不合格（退出码 1）就改到合格；提醒里说得对的也改掉。

写不了那个文件夹时（沙箱只让写当前工作目录），不要换地方存：把 JSON 放在一个代码块里给用户，告诉用户复制后在插件侧边栏里按 Ctrl+V 就能导入。

## 4. 告诉用户

回复里写这几样，不用长：

1. 存在哪（完整路径），收藏夹名和本地文件夹名（自己起的要说是自己起的）。
2. 分了哪几组，每组看什么，一组一句。
3. 下一步：在 Chrome 打开 PinBoardLock 侧边栏点“刷新”，选这份调研单；缺的收藏夹和分区点“新建这些”；然后点关键词收图，收完点侧边栏里的“⬇ 下载”按钮。

用户看完想调整分组或关键词，直接改同一个文件再跑一次检查，让用户再点一次“刷新”。
