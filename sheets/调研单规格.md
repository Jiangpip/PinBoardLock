# 调研单规格

这个文件夹里的每个 `*.json` 是一份调研单。PinBoardLock 插件的侧边栏点“刷新”会把它们读进去。

## 谁往这里放

- **网页版 AI**（ChatGPT、Claude、Gemini、DeepSeek……）：在插件侧边栏“导入”里点“复制给 AI 的说明”贴给它。它按下面的格式回一个 JSON 代码块后，插件在聊天页里认出来会自动存到这里，页面右下角有提示。
- **Claude Code / Codex**：安装脚本装了 `pin-research` 技能，说“做个图片调研”就会按这份规格出调研单，直接存成 `sheets\<调研主题>.json`，并用 `tools\sheet-check.js` 检查。
- **手动**：复制 JSON 后在侧边栏空白处按 Ctrl+V，或者在“导入”里贴，都会顺手存一份到这里。

## 格式

```json
{
  "title": "调研主题（中文）",
  "board": "Pinterest 收藏夹名",
  "folder": "下载到本地的文件夹名（可以不写）",
  "note": "这次调研要解决什么（可以不写）",
  "groups": [
    {
      "name": "分组名（也是收藏夹里的分区名）",
      "note": "这一组要看什么、怎么判断合不合适",
      "keywords": ["pinterest search phrase", "another phrase", { "q": "wu guanzhong landscape", "note": "吴冠中" }]
    },
    {
      "name": "散图",
      "section": false,
      "keywords": ["不分区、直接进收藏夹的关键词"]
    }
  ]
}
```

- `title` + `board` 相同就算同一份：再存一次是更新，不会多出一份。
- `section`：不写 = 分区名等于分组名；写字符串 = 分区用这个名字；写 `false` = 不分区，直接进收藏夹。
- `folder`：不写 = `默认根目录\调研主题`；写名字 = `默认根目录\这个名字`；写盘符开头的完整路径就原样用。默认根目录是 `host\config.json` 的 `defaultRoot`。
- `privacy`：写 `"secret"` 表示新建收藏夹时建成私密。
- 一个文件里放数组 `[ {...}, {...} ]` 表示多份。

## 关键词怎么写

1. 按“看的角度”分 3–6 组（用色 / 笔触 / 构图 / 代表作者 / 相邻风格），每组 4–8 个关键词。
2. 写 Pinterest 上真能搜出图的词，以英文为主；这个风格在日文、中文圈更常见时，把对应语言的词也放进去。
3. 要具体：作者名、流派名、技法名、年代、题材组合。不要只写 "beautiful art" 这种泛词。
